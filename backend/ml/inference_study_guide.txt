# inference.py Study Guide
## Bangus Buhai Water Quality Prediction - ML Inference Module

---

## OVERALL FLOW (Big Picture)

```
User provides 48 WaterLog readings (temperature, pH, turbidity)
         │
         ▼
prepare_sequence() → Normalize with scaler → Shape: (1, 48, 3) tensor
         │
         ▼
predict() → For each hour (1-4):
    1. Model predicts next step (1, 3)
    2. Inverse transform to real values
    3. Store prediction
    4. Append prediction to sequence, drop oldest (autoregressive)
         │
         ▼
Returns dict: {hour_1: {temp, pH, turbidity}, hour_2: {...}, hour_3: {...}, hour_4: {...}}
```

**Purpose**: Load trained LSTM model + scaler, take 48 historical water readings, predict next 4 hours of water quality.

### Resource Loading (Lines 37-73)

#### `load_resources()` (Lines 37-61)

```python
def load_resources():
    global _model, _scaler
    
    if _model is None:
        # Check file exists
        if not MODEL_PATH.exists():
            raise FileNotFoundError(...)
        
        # 1. Create model architecture
        _model = BangusLSTM()
        
        # 2. Load saved weights
        checkpoint = torch.load(MODEL_PATH, map_location=torch.device('cpu'), weights_only=False)
        _model.load_state_dict(checkpoint["state_dict"])
        
        # 3. Set to evaluation mode (disables dropout, batch norm updates)
        _model.eval()
    
    if _scaler is None:
        if not SCALER_PATH.exists():
            raise FileNotFoundError(...)
        _scaler = joblib.load(SCALER_PATH)
```

**Key concepts**:
- `torch.load(..., map_location='cpu')`: Load model on CPU even if trained on GPU
- `weights_only=False`: Allows loading full checkpoint (including optimizer state, etc.)
- `load_state_dict()`: Loads only the learned parameters (weights/biases)
- `model.eval()`: Critical! Sets dropout/batchnorm to inference mode

#### `get_model()` & `get_scaler()` (Lines 64-73)

```python
def get_model():
    if _model is None:
        load_resources()
    return _model

def get_scaler():
    if _scaler is None:
        load_resources()
    return _scaler
```

**Pattern**: Lazy loading. Resources load on first use, not at import time.

### Preprocessing (Lines 80-122)

#### `logs_to_numpy(logs)` (Lines 80-95)

```python
def logs_to_numpy(logs: List[WaterLog]) -> np.ndarray:
    return np.array(
        [
            [log.temperature, log.pH, log.turbidity]
            for log in logs
        ],
        dtype=np.float32,
    )
```

**Input**: List of 48 WaterLog objects (oldest → newest)
**Output**: numpy array shape **(48, 3)** — 48 timesteps, 3 features each

**Example**:
```
Input:  [WaterLog(temp=28.5, pH=7.2, turbidity=5.1), WaterLog(temp=28.6, pH=7.1, turbidity=5.0), ...]
Output: [[28.5, 7.2, 5.1],
         [28.6, 7.1, 5.0],
         ...]  # shape (48, 3)
```

#### `prepare_sequence(logs)` (Lines 98-122)

```python
def prepare_sequence(logs: List[WaterLog]) -> torch.Tensor:
    if len(logs) < SEQ_LENGTH:
        raise ValueError(f"Model requires {SEQ_LENGTH} water logs, got {len(logs)}.")
    
    scaler = get_scaler()
    data = logs_to_numpy(logs)
    
    with warnings.catch_warnings():
        warnings.filterwarnings("ignore", message="X does not have valid feature names", category=UserWarning)
        scaled = scaler.transform(data)
    
    sequence = scaled[-SEQ_LENGTH:]           # Take last 48: shape (48, 3)
    sequence = np.expand_dims(sequence, axis=0)  # Add batch dim: shape (1, 48, 3)
    return torch.as_tensor(sequence, dtype=torch.float32)
```

**Step by step**:
1. **Validate**: Need at least 48 logs
2. **Convert**: WaterLog list → numpy (48, 3)
3. **Scale**: Apply fitted scaler (normalize to 0-1 or standardize)
4. **Slice**: Take last 48 entries (in case more provided)
5. **Batchify**: Add batch dimension → (1, 48, 3)
6. **Tensor**: Convert to PyTorch tensor

**Why warnings.catch_warnings?**: sklearn scaler complains about missing feature names when transforming numpy arrays (vs pandas DataFrames). We suppress this known warning.

**Shape evolution**:
```
logs (list of 48) 
    → data: (48, 3)
    → scaled: (48, 3)
    → sequence[-48:]: (48, 3)
    → expand_dims: (1, 48, 3)  # batch=1, seq_len=48, features=3
    → tensor: (1, 48, 3)
```

### Prediction (Lines 129-165)

#### `predict(logs)` — Main Entry Point

```python
def predict(logs: List[WaterLog]) -> dict:
    model = get_model()
    scaler = get_scaler()
    sequence = prepare_sequence(logs)
    predictions = {}
    
    with torch.no_grad():                    # Disable gradient computation (faster, less memory)
        for horizon in range(1, 5):          # Predict hour 1, 2, 3, 4
            # 1. Forward pass
            prediction_scaled = model(sequence)  # Output: (1, 3)
            
            # 2. Convert to numpy
            pred_np = prediction_scaled.cpu().numpy()  # (1, 3)
            
            # 3. Inverse transform to real values
            with warnings.catch_warnings():
                warnings.filterwarnings("ignore", message="X does not have valid feature names", category=UserWarning)
                real_pred = scaler.inverse_transform(pred_np)[0]  # (3,)
            
            # 4. Store prediction
            predictions[f"hour_{horizon}"] = {
                "temperature": float(real_pred[0]),
                "pH": float(real_pred[1]),
                "turbidity": float(real_pred[2]),
            }
            
            # 5. AUTOREGRESSIVE UPDATE
            next_step = prediction_scaled.unsqueeze(1)      # (1, 1, 3)
            sequence = torch.cat([sequence[:, 1:, :], next_step], dim=1)  # (1, 48, 3)
    
    return predictions
```

**Autoregressive forecasting explained**:
```
Initial sequence:  [t-47, t-46, ..., t-1, t]     (48 steps)
                                    │
                                    ▼
Predict t+1  ──►  Append t+1, drop t-47
                                    │
                                    ▼
New sequence:      [t-46, ..., t, t+1]     (still 48 steps)
                                    │
                                    ▼
Predict t+2  ──►  Append t+2, drop t-46
... repeat for t+3, t+4
```

**Key operations**:
| Operation | Shape Change | Purpose |
|-----------|--------------|---------|
| `model(sequence)` | (1, 48, 3) → (1, 3) | Predict next timestep |
| `.unsqueeze(1)` | (1, 3) → (1, 1, 3) | Add time dimension |
| `sequence[:, 1:, :]` | (1, 48, 3) → (1, 47, 3) | Drop oldest timestep |
| `torch.cat(..., dim=1)` | (1, 47, 3) + (1, 1, 3) → (1, 48, 3) | Append new, keep length 48 |

**`torch.no_grad()`**: Disables autograd engine. Critical for inference — saves memory and computation.

**Output format**:
```python
{
    "hour_1": {"temperature": 28.5, "pH": 7.2, "turbidity": 5.1},
    "hour_2": {"temperature": 28.6, "pH": 7.1, "turbidity": 5.0},
    "hour_3": {"temperature": 28.7, "pH": 7.0, "turbidity": 4.9},
    "hour_4": {"temperature": 28.8, "pH": 6.9, "turbidity": 4.8},
}
```

## MUST-KNOW CHEAT SHEET

### Core Concepts

| Concept | What It Is | Where Used |
|---------|------------|------------|
| **LSTM** | Long Short-Term Memory — RNN variant that handles long sequences | `BangusLSTM` class (imported) |
| **Autoregressive** | Each prediction feeds into next prediction | `predict()` loop (lines 141-163) |
| **Scaler** | Normalizes features to similar range (0-1 or z-score) | `prepare_sequence()` + `predict()` inverse |
| **Sequence length** | Fixed window of history (48 timesteps) | `SEQ_LENGTH = 48` |
| **Batch dimension** | First dim = batch size (always 1 here) | `np.expand_dims(..., axis=0)` |
| **eval() mode** | Disables dropout, freezes batchnorm stats | `load_resources()` line 53 |
| **no_grad()** | Disables gradient tracking for inference | `predict()` line 140 |

### Data Flow Shapes

```
WaterLog[48] 
    → logs_to_numpy() 
    → (48, 3) numpy
    → scaler.transform() 
    → (48, 3) scaled
    → expand_dims(axis=0) 
    → (1, 48, 3) numpy
    → torch.as_tensor() 
    → (1, 48, 3) tensor  ← MODEL INPUT

model(sequence) 
    → (1, 3) tensor  ← PREDICTION (scaled)
    → .cpu().numpy() 
    → (1, 3) numpy
    → scaler.inverse_transform() 
    → (1, 3) real values
    → [0] index 
    → (3,) array [temp, pH, turbidity]
```

### Autoregressive Update (The Tricky Part)

```python
# Before: sequence = (1, 48, 3)  -- 48 timesteps
next_step = prediction_scaled.unsqueeze(1)    # (1, 3) → (1, 1, 3)
sequence = torch.cat([sequence[:, 1:, :], next_step], dim=1)
# sequence[:, 1:, :] = drop first timestep → (1, 47, 3)
# cat on dim=1 (time) → (1, 48, 3) -- back to 48 timesteps
```

**Visual**:
```
Time:    t-47  t-46  ...  t-1   t    →  predict t+1
Index:    [0]   [1]        [46] [47]
                              │
                              ▼ drop [0], append t+1
Time:    t-46  ...  t-1   t   t+1  →  predict t+2
Index:    [0]         [45] [46] [47]
```

### Common Gotchas

| Issue | Cause | Fix |
|-------|-------|-----|
| "X does not have valid feature names" | sklearn scaler on numpy array | `warnings.filterwarnings("ignore", ...)` |
| Model predicts nonsense | Forgot `model.eval()` | Always call after loading |
| OOM / slow | Forgot `torch.no_grad()` | Wrap inference in `with torch.no_grad():` |
| Shape mismatch | Wrong sequence length | Ensure exactly 48 logs provided |
| CPU/GPU mismatch | Model saved on GPU, loading on CPU | `map_location=torch.device('cpu')` |

## MENTAL MODEL SUMMARY

1. **Startup**: App starts → `is_model_loaded()` = False
2. **First request**: `predict()` → `get_model()` → `load_resources()` loads model + scaler into globals
3. **Preprocess**: 48 WaterLogs → numpy → scale → tensor (1, 48, 3)
4. **Predict 4 hours**: Loop 4 times: predict → inverse_scale → store → update sequence (autoregressive)
5. **Return**: Dict with 4 hours of predictions
6. **Subsequent requests**: Reuse cached `_model` and `_scaler` (fast)

The model "slides" a 48-timestep window forward, predicting one step at a time, using its own predictions as future inputs.
